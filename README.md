# 📊 Customer Churn Prediction & Analytics Dashboard

## 🔍 Overview

This project analyzes customer churn behavior and builds a machine learning model to predict which customers are likely to leave a service. It also provides an interactive dashboard for business insights.

---

## 🎯 Objectives

* Identify factors contributing to customer churn
* Predict high-risk customers using machine learning
* Provide actionable insights to reduce churn

---

## 🧠 Key Features

* Exploratory Data Analysis (EDA)
* Data Cleaning & Feature Engineering
* Machine Learning Model (Logistic Regression & Random Forest)
* Feature Importance Analysis
* High-Risk Customer Detection
* Interactive Dashboard using Streamlit

---

## 📊 Key Insights

* Customers with month-to-month contracts have higher churn
* New customers (low tenure) are more likely to leave
* Higher monthly charges increase churn probability

---

## ⚙️ Tech Stack

* Python (Pandas, NumPy)
* Scikit-learn (ML models)
* Seaborn & Matplotlib (Visualization)
* Streamlit (Dashboard)

---

## 🚀 How to Run

1. Clone the repository
2. Install dependencies

   ```
   pip install -r requirements.txt
   ```
3. Run the dashboard

   ```
   streamlit run app.py
   ```

---

## 📌 Conclusion

This project demonstrates an end-to-end data science workflow, from data analysis to deployment, helping businesses understand and reduce customer churn.
